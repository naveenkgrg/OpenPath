# OpenPath

**OpenPath** is a community-driven, open framework that closes the gap between entering the tech field and being fully productive — through structured, hands-on experience with the tools, workflows, and real projects that modern teams use every day.

It covers:
- Git and GitHub workflows used in real engineering teams
- AI-assisted development with Copilot, Cursor, and Claude
- Open-source contribution — your first merged pull request
- AI key concepts: context, skills, and agents
- MCP integration — connecting Claude to your filesystem and GitHub
- End-to-end MVP delivery — from idea to deployed app
- Free learning resources across programming, cloud, and more
- Internship and mentorship programs for students and early-career contributors

Everything here is free, open source, and beginner-friendly.

## Labs

| Lab | Topic | Time |
|-----|-------|------|
| [Lab 1](labs/lab01-github-basics/README.md) | GitHub & Git basics — account, install, SSH, first commit, profile README | 30 min |

| [Lab 6](labs/lab06-prompt-context/README.md) | AI key concepts — context, skills, and agents | 30–45 min |
| [Lab 7](labs/lab07-mcp-integration/README.md) | MCP integration — connect Claude Desktop to GitHub and your filesystem | 45–60 min |
| [Lab 8](labs/lab08-mvp-delivery/README.md) | End-to-end MVP delivery — from idea to deployed app | 2–4 hours |

## What you leave with

After completing all labs:

- **A live deployed product** — built by you, at a public URL you own and can demo
- **A visible contribution record** — GitHub activity and an open-source contribution on record
- **Real systems skills** — API integration patterns that apply across every future role
- **Confidence to demonstrate work** — a rehearsed demo and talking points for interviews
