# How to Contribute

## Beginner contribution checklist

- Create a GitHub profile with a short bio and basic details.
- Read the project's README and CONTRIBUTING guide.
- Pick a small change like docs, typos, or a beginner issue.
- Create a branch, make the change, and open a PR.
- Be respectful and open to feedback from maintainers.

## Project due diligence checklist

- Check recent activity in issues and pull requests.
- Confirm a clear open source license is present.
- Look for a code of conduct and community guidelines.
- See if maintainers respond in a reasonable timeframe.

## PR quality checklist

- Use a clear, descriptive title.
- Keep scope small and focused.
- Write a helpful description of what changed and why.
- Add screenshots for documentation or UI changes.
