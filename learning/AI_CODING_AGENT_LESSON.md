# AI Coding Agent Lesson

## What is an AI coding agent?

An AI coding agent is a tool that helps you write, review, and improve code. You type a natural language prompt, and it generates code, suggestions, or explanations in return.

Common uses:
- Generate starter code for a small web project
- Fix bugs in HTML, CSS, or JavaScript
- Explain how a code block works
- Suggest alternative approaches

## Why use one?

AI agents can accelerate learning and reduce repetitive work. They are useful when you want to:
- prototype an idea quickly
- learn a new pattern or library
- fix syntax problems or missing logic
- get suggestions for layout, styling, or structure

## How to use them effectively

1. Start with a small, clear idea.
2. Write a specific prompt.
3. Generate the code.
4. Test the output immediately.
5. Review and refine the result yourself.

### Good prompt habits

- Be specific about the page or feature you want.
- Mention the languages and files needed.
- Ask for a full example you can run.
- Request comments if you want explanations.

Example prompt:

`Create a simple HTML page with a responsive profile card, styled buttons, and a blue gradient background using CSS.`

## Simple workflow

- Pick one practice project: a profile page, a simple game, or an animated wallpaper.
- Ask the AI for complete code in `index.html`, `styles.css`, and `script.js`.
- Open the page in a browser and look for visual or console issues.
- Ask the AI to fix any problems, then verify the result.

## Risks and limitations

AI is helpful, but not perfect. It can:
- introduce bugs
- generate insecure or outdated code
- misunderstand your requirements
- add unnecessary complexity

Always read the generated code, test it, and simplify anything extra.

## Recommended tools

- GitHub Copilot for inline code help in VS Code
- ChatGPT or Claude for complete code examples and follow-up questions
- Cursor for interactive prompt-driven editing

## Key takeaway

AI coding agents are tools, not replacements. Use them to speed up your workflow, but stay in control: guide the prompts, validate the code, and learn from the output.
