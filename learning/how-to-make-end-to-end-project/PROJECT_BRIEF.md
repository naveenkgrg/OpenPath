# Project Brief: OpenPath NearMe

## Idea

Build a simple app that helps users find nearby:
- tech conferences
- hackathons
- meetups
- community events

## Product Name

`OpenPath NearMe`

## Problem

People often discover local tech events too late because event information is scattered across different websites and communities.

## Target User

- students
- developers
- job seekers
- open-source learners

## MVP Features

1. Search by city
2. Show upcoming local tech events
3. Show title, date, venue, type, and link

## Optional Later Features

- event type filters
- saved events
- login
- map view
- recommendations

## Suggested Stack

- Next.js
- GitHub
- Vercel
- optional Supabase or Neon

## Deliverables

- GitHub repository
- live URL
- README

## Keep It Lean

If time is limited:
- use mock event data
- build one search form
- render a simple result list
- deploy

That is enough for a strong first MVP.
